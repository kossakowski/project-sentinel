# Jev and Luna pilot — 2026-09-22

Jev is promising enough for further evaluation. This run does not justify switching the production classifier. It matched the coarse alert tier and incident grouping well, but made factual errors, including omitting Poland from two critical reports.

## Scope

- The run used 64 existing synthetic diagnostic cases: 16 each in Polish, English, Ukrainian and Russian.
- There were 63 reviewed labels and one disputed label. The disputed case was queried but excluded from semantic scores. These are not fresh, independently approved ground-truth labels.
- Both models received identical article and prior-source context. Reference history used prior annotations for grouping, not model predictions.
- Jev was pinned to `jev-1.13.0`. Luna used the configured direct `gpt-5.6-luna`, reasoning `none`, and its full classification output schema.
- No runtime alert transports or production database were used. Summaries, supporting quotations, candidate retrieval and exact duplicate/update/escalation labels were not graded.

Both models assigned a critical score to all 32 scored critical cases. Neither produced a critical overcall in this set. This measures scores, not delivered notifications. Narrow 9-versus-10 fixture labels can affect the exact-range result without changing the coarse tier.

## Findings requiring review

- Jev returned urgency 10 and attack country PL but no affected country for `v2h-pl-01-b` (a missile hit a Polish radar) and `v2h-ru-04-b` (a hostile missile was still over Polish territory). Luna returned PL in both. The independent Jev answers need consistency checks before runtime use.
- Jev added Lithuania to Latvian reporting in `v2h-pl-01-d` and `v2h-pl-02-c`, and added Latvia to Lithuanian reporting in `v2h-uk-01-d`.
- Jev disagreed with status labels most often in Ukrainian: 12/16 correct, versus 14/15 English, 15/16 Polish and 13/16 Russian. Samples are too small for a language ranking.
- Two Jev status disagreements exceeded 0.9 confidence. Both concern completed exercises, and Luna also chose resolved where the fixture expects historical. Review the label/definition boundary before treating these as established model errors.
- There are 45 cases with some difference between providers, including harmless score differences within one tier. Full differences are in the machine-readable report.

## Cost, recovery and reproducibility

Total estimated cost was **$0.04895478**, below the combined $0.25 cap. The ledger contains 128 settled calls and no unresolved reservations. Costs use the configured rates; they are not reconciled invoices. Luna generated additional text, so the timings/costs are not an equal-output comparison.

The first attempt stopped after 60 responses because the local validator rejected rounded probabilities summing to 0.99. The validator now tolerates the mathematical rounding bound while preserving raw values. The resumed run reused all 60 responses, made 68 new calls, and copied the original spending ledger. No completed inference request was sent again. The original run remains intact.
